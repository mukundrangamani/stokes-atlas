# Stokes atlas accompanying [Expiscating the black hole singularity in holography](https://arxiv.org/abs/2611.abcde)

An interactive visualizer for Stokes graphs accompanying the manuscript [Expiscating the black hole singularity in holography](https://arxiv.org/abs/2611.abcde). We illustrate the examples studied in the aforementioned reference. The Stokes graphs are depicted for the both general-momentum and core regimes of planar and global Schwarzschild–AdS, planar Reissner–Nordström–AdS black holes. The
notation conventions for the coordinates, turning-points, as well as the phase conventions for frequency follow what is used in manuscript. The parameters used are indicated for each example considered.

Open index.html in a browser, or browse the GitHub Pages site. The viewers
work offline and need no installation. Drag a sphere or use the arrow keys
to rotate it; select roots or crossings to highlight their trajectories.

- General momentum: 45 graphs, five backgrounds, three momenta and phases.
- Resolved core: ten neutral graphs and three RNAdS5 graphs.
- Print atlases: general-momentum and neutral-core collections.
- Notation: coordinates, frequency phase, turning-point and horizon labels.

Please cite [Expiscating the black hole singularity in holography](https://arxiv.org/abs/2611.abcde) by Hewei Frederic Jia and Mukund Rangamani.
